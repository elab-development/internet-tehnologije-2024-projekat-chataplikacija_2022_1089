# 💬 Chat Aplikacija (Laravel + React)

Ovaj projekat predstavlja razvoj jednostavne **chat aplikacije** korišćenjem modernih tehnologija:  
- **Laravel (PHP framework)** – backend logika i API  
- **React (JavaScript biblioteka)** – frontend korisnički interfejs  
- **MySQL** – relaciona baza podataka  
- **Laravel Sanctum** – autentikacija i zaštita API ruta  

---

## 🚀 Funkcionalnosti
- Registracija, prijava i odjava korisnika  
- Ulazak u aplikaciju kao **user**, **guest** ili **admin**  
- Kreiranje i prikaz grupa za razgovor  
- Upravljanje grupama (dodavanje, brisanje, napuštanje)  
- Razmena poruka (tekst, emodžiji, gifovi)  
- Pretraga poruka i promena pozadina u chatu  
- Administratorske privilegije (upravljanje grupama, pregled statistike o broju poruka)  

---

## 🛠️ Tehnologije
- **Backend:** PHP, Laravel, Eloquent ORM  
- **Frontend:** React, Axios, React Router, Hooks  
- **Baza podataka:** MySQL  
- **Autentikacija:** Laravel Sanctum  
- **Dijagrami i metodologija:** uprošćena Larmanova metoda (iterativno–inkrementalni razvoj)  

---

## 📂 Struktura projekta
- `backend/` → Laravel API (kontroleri, modeli, rute, migracije, seeders)  
- `frontend/` → React aplikacija (komponente, hooks, CSS stilovi)  
- `database/` → MySQL šema i inicijalni podaci  

---

## 📸 Prikaz aplikacije
- **User panel** → kreiranje grupa, razmena poruka, dodavanje korisnika  
- **Guest panel** → ograničeni pristup samo javnim grupama  
- **Admin panel** → pregled svih korisnika i grupa, grafikon aktivnosti  

---

## 📊 Biznis model
Osnovne funkcionalnosti su besplatne.  
Napredne opcije (privatne grupe, dodatna administracija) mogu se omogućiti putem pretplate.
